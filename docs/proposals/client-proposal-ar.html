١. مقدمة

تقدّم الإبداع التقني هذا العرض لتنفيذ وتسليم نظام إدارة مخازن احترافي متعدد الشركات (Multi-tenant SaaS)، يمكّن العميل من تشغيل عمليات المخزون والشراء والبيع والتحويل عبر واجهة ويب حديثة، مع لوحة إدارة للمنصة لإنشاء المستأجرين وإدارة الاشتراكات.

السعر المعروض USD 5,000 هو سعر ثابت شامل لنطاق العمل الموضّح في هذا المستند، ولا يتغيّر إلا إذا طلب العميل توسيعًا مكتوبًا خارج النطاق.

٢. أهداف النظام

  • إدارة مخزون دقيقة متعددة المخازن مع أرصدة وحركات وتسويات.
  • دعم أوامر الشراء والاستلام وأوامر البيع والشحن والتحويلات بين المخازن.
  • عزل بيانات كل مستأجر (شركة) بشكل صارم مع صلاحيات وأدوار.
  • لوحة مشغّل لإنشاء المستأجرين وتعليقهم ومتابعة الجاهزية والاستخدام.
  • واجهات عربية افتراضية واتجاه من اليمين لليسار، مع تبديل للإنجليزية.
  • أساس تقني قابل للتوسّع والنشر عبر Docker مع فحوصات صحة ومراقبة أساسية.

٣. نطاق العمل المشمول بالسعر الثابت

المكوّن ما يشمله التسليم الحالة
واجهة المستأجر (Web) تسجيل الدخول، لوحة التحكم، المنتجات، المخزون، المشتريات، المبيعات، التحويلات، المزامنة، إدارة المستخدمين والأدوار مشمول
لوحة مشغّل المنصة تطبيق React منفصل: دخول المشغّل، قائمة المستأجرين، الإنشاء، التعليق/الاستئناف، الاشتراك، الاستخدام والجاهزية مشمول
واجهة برمجة التطبيقات API مصادقة JWT، الكتالوج، المخازن والمخزون، المشتريات، المبيعات، التحويلات، المزامنة، إدارة المستخدمين، منصة SaaS مشمول
قاعدة البيانات PostgreSQL مع ترحيلات EF، عزل المستأجرين، أدوار وصلاحيات نظامية مشمول
التشغيل والنشر Docker Compose (قاعدة بيانات + Redis + API)، فحوصات Live/Ready، تحديد معدّل الطلبات، سجلات منظمة، إعداد إنتاج، توثيق النسخ الاحتياطي والترحيل مشمول
التوثيق وثائق معمارية وتشغيلية للمشروع، وتعليمات التشغيل المحلي مشمول
التدريب والتسليم جلسة تسليم واحدة (حتى ساعتين) + دليل استخدام مختصر بالعربية مشمول

٥. ما لا يشمله السعر الثابت

البنود التالية خارج نطاق الـ USD 5,000 ويمكن تقديم عرض منفصل لها عند الطلب:

  • تطبيق الجوال (Flutter) والعمل دون اتصال الكامل على الأجهزة المحمولة.
  • تكامل بوابات الدفع الإلكتروني (Stripe وغيرها).
  • تقارير PDF/Excel المتقدمة ولوحات مؤشرات مخصّصة حسب طلب العميل.
  • جرد المخزون الدوري (Stock counts) كوحدة مستقلة موسّعة.
  • استضافة سحابية مدفوعة، وشهادات SSL التجارية، والنسخ الاحتياطي المدارة لدى مزوّد خارجي.
  • تخصيصات UI/UX خارج الهوية الحالية، أو ربط مع أنظمة ERP طرف ثالث.
  • دعم فني شهري بعد فترة الضمان (انظر بند الضمان).
